🎨 SAM3 Image Annotation Tool

Upload an image and draw a box around the object you want to segment

📁 Click to upload or drag and drop
Supported formats: JPG, PNG, WebP

📝 How to use:

  1. Click and drag on the image to draw a box around the object
  2. Optionally, add a text description of what you're looking for
  3. Click "Segment Image" to detect the object
  4. Download the masked image when ready
